## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Open the project

```bash
cd YOUR-REPOSITORY
```

### 3. Run the website

Open `index.html` in a browser, or use **VS Code → Live Server**.

## 🖼️ Add Your Profile Photo

Place your image in the project folder:

```text
shubham.jpg
```

Then use:

```html
<img src="shubham.jpg" alt="Shubham Kumar">
```

## 📄 Add Your Resume

Place your resume in the project folder:

```text
resume.pdf
```

The **Download CV** button will then download your resume.

## 🎨 Customization

| File | Purpose |
|---|---|
| `index.html` | Website structure and content |
| `style.css` | Design, colors and responsive layout |
| `script.js` | Menu, theme switcher and interactions |

You can customize your name, photo, email, skills, projects, social links and resume.

## 🌙 Dark / Light Mode

The portfolio includes a Dark Mode / Light Mode switch. The selected theme is stored using browser `localStorage`, so the preference remains after refreshing the page.
